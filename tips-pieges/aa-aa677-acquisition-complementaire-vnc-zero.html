AS01 : avertissement AA677, acquisition complémentaire avec VNC à zéro

FI-AAAS01AA677Clé d'amortissement

Symptôme

À l'enregistrement d'une immobilisation (AS01), le calcul d'amortissement remonte « acquisition complémentaire en zone 01 bien que la valeur nette comptable soit 0 » (AA677).

Cause

Une acquisition complémentaire a été comptabilisée en cours d'exercice alors que la VNC avait déjà atteint zéro cette année-là. Le montant d'amortissement peut devenir faux, d'où l'avertissement (ce n'est pas bloquant : le document peut être comptabilisé).

Solution (fils et KBA)

  • Contrôler le montant d'amortissement réel de l'immobilisation.
  • Si le montant est faux, trois options décrites dans le texte long du message : passer le contrôle de période de la clé d'amortissement pour les acquisitions complémentaires à « début d'exercice », ou comptabiliser ces acquisitions sur des sous-numéros, ou corriger par une écriture manuelle d'ajustement du montant de correction.

Pièges

Piège Message de type avertissement : facile à ignorer en masse (chargement, migration) alors que l'amortissement peut être erroné.
Piège Changer le contrôle de période de la clé impacte toutes les immobilisations qui l'utilisent.

Tips

Tip Pour les cas ponctuels, les sous-numéros évitent de toucher à la clé d'amortissement.
Tip Lire le texte long du message : l'aide SAP y détaille les trois options.
