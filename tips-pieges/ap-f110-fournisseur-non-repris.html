F110 : un fournisseur n'est pas repris dans la proposition de paiement

FI-APF110Liste d'erreursBlocage

Symptôme

Le run de paiement automatique ne génère pas de paiement pour un fournisseur, alors que ça fonctionnait jusqu'ici. Le message sur les sociétés absentes de la proposition est générique.

Cause

Deux causes principales ressortent des fils : le fournisseur est bloqué, ou il figure déjà dans une autre proposition de paiement non terminée qui verrouille son compte. Autre cas : aucune partie ouverte ne correspond aux critères du run, ou la facture n'est pas encore échue à la date du run (le journal de proposition indique la première date de paiement possible).

Solution (fils et KBA)

  • Dans F110, sélectionner le run concerné puis ouvrir la liste d'erreurs (Édition > Proposition > Liste d'erreurs) : elle donne la raison.
  • Vérifier les parties ouvertes du fournisseur dans FBL1N pour les dates du run, puis lire le journal complémentaire pour voir pourquoi des factures ont été ignorées.
  • Compte bloqué par une proposition précédente : terminer le run précédent ou supprimer sa proposition, puis relancer.
  • Blocage fournisseur : le lever dans XK02 et vérifier le marquage pour suppression dans XK05. Blocage de paiement sur facture : le lever manuellement.
  • Facture non échue : contrôler les conditions de paiement ; ajuster la date du run à la date d'échéance du journal de proposition.

Pièges

Piège Un message d'adresse dans le journal est souvent informatif et n'explique pas l'absence de paiement.
Piège Une proposition oubliée verrouille le fournisseur pour tous les autres runs.
Piège La date de run compte : une facture peut ouvrir droit à escompte la veille et n'être échue que bien plus tard.

Tips

Tip Toujours commencer par la liste d'erreurs avant de toucher à la configuration.
Tip Conseil de pratique : purger régulièrement les propositions non traitées.
