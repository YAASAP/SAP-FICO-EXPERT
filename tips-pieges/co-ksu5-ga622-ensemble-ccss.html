KSU5 : message GA622, erreur de lecture d'ensemble (table CCSS)

COKSU5GA622RK811XSTT811X

Symptôme

Au premier lancement de l'imputation (KSU5) sur ECC 6.0, le message GA622 « Read error in set for table CCSS » interrompt le traitement : la configuration (T811X) référence un ensemble qui n'existe pas.

Cause

Erreur de configuration d'allocation, typique après changement de release ou copie de mandant incomplète d'après le texte du message. La note 34087 décrit ce message.

Solution (fils et KBA)

  • Lancer le programme RK811XST, puis relancer l'allocation (seule solution proposée dans le fil).

Pièges

Piège Aucune réponse acceptée dans le fil : solution non confirmée par l'auteur.
Piège Si l'exécution de programmes via SE38 est restreinte (audit), il faut passer par la procédure interne ou un autre contrôle d'accès.

Tips

Tip Conseil de pratique : contrôler les ensembles référencés par les cycles après copie de mandant.
