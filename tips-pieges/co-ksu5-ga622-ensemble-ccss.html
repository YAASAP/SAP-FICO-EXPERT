KSU5 : message GA622, erreur de lecture d'ensemble (table CCSS)

COKSU5GA622RK811XSTT811X

Symptôme

Au premier lancement de l'imputation (KSU5) sur ECC 6.0, le message GA622 « Read error in set for table CCSS » interrompt le traitement : la configuration (T811X) référence un ensemble qui n'existe pas.
