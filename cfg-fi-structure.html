OX02 · OX15 · OB13 · OB29 · OBBO · OBC4Structure d'entreprise FI et variantes

Société, code société, plan comptable et trois variantes (exercice, périodes ouvertes, statut de zone) forment le socle de toute comptabilité SAP. Tu les définis une fois, puis tu les affectes au code société.

Où ça se passe

Racine SPRO : Enterprise Structure > Definition / Assignment > Financial Accounting, puis Financial Accounting Global Settings (exercice, périodes, statuts de zone). Transactions principales : OX02, OX15, OX16, OB13, OB62, OB29, OB37, OBBO, OBBP, OBC4, OBC5.
