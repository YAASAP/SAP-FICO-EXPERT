Principe · OData en une page

Un service OData est une URL qui renvoie des données typées, filtrables et navigables

OData est un protocole REST normalisé sur HTTP. Chez SAP, c'est la porte d'entrée de Fiori, des API S/4HANA et de la plupart des intégrations modernes.

Le client envoie une requête HTTP (GET, POST, PUT, MERGE, PATCH, DELETE) vers une adresse de service. Le serveur répond en JSON ou en ATOM/XML. Le contrat du service est publié dans un document appelé $metadata : il décrit les entités, leurs champs, leurs clés et les liens entre elles.

1 · Racine du serviceUne adresse unique, par exemple /sap/opu/odata/sap/NOM_SERVICE/
→
2 · $metadataLe contrat : types d'entités, jeux, associations
→
3 · Jeu d'entitésLa collection interrogeable, par exemple JournalItemSet
→
4 · EntitéUne ligne désignée par sa clé : Set(Cle='1')
→
5 · NavigationLe lien vers une entité liée : Header/Items

Vocabulaire minimal

  • Type d'entité : la structure d'une ligne (champs, types, clés). C'est l'équivalent d'une structure ABAP avec ses clés.
  • Jeu d'entités (entity set) : la collection de lignes d'un type. C'est ce que l'on interroge, comme une table.
  • Propriété de navigation : le lien d'une entité vers une autre (un en-tête de pièce vers ses lignes).
  • Import de fonction / action : une opération qui n'est pas un simple CRUD (par exemple « valider »).
  • Jeton CSRF : obligatoire pour toute écriture. On le demande avec un GET (en-tête x-csrf-token: Fetch), puis on le renvoie dans la requête d'écriture avec le même cookie de session.

OptionRôleExemple (fictif)

$selectNe ramener que certaines colonnes$select=AccountingDocument,GLAccount
$expandCharger les entités liées dans la même réponse$expand=to_Items
$top / $skipPagination$top=50&$skip=100
$orderbyTrier$orderby=PostingDate desc
$countCompter (V4 : $count=true ; V2 : /$count ou $inlinecount=allpages)Voir section V2 et V4
$formatForcer json ou atom (V2)$format=json

PiègeLes espaces et les apostrophes d'un $filter doivent être encodés par le client HTTP. Une erreur 400 sur un filtre vient presque toujours d'un littéral mal quoté ou d'une propriété non filtrable dans le modèle.
