KOT2_OPATypes d'ordres internes

Le type d'ordre fixe le comportement d'un ordre interne : profil de règlement, plage de numéros, profil de planification. KOT2_OPA est la transaction de maintenance de ces types.

Où ça se passe

Transaction KOT2_OPA, activité IMG « Define Order Types » (code complémentaire S_ALR_87005053) ; chemin SPRO exact à confirmer dans ton IMG (selon release)
