IMG types de mouvementTypes de mouvement d'immobilisations

Les types de mouvement classent les opérations FI-AA : acquisitions, cessions, transferts. Tu en crées de nouveaux en copiant un type standard, avec les clés réservées au client.

Où ça se passe

Chemin SPRO Gestion financière > Comptabilité des immobilisations > Transactions (Acquisitions, Cessions, Transferts), table TABW ; pour les transferts : « Définir les types de mouvement pour les transferts » ; chemin SPRO exact à confirmer dans ton IMG (selon release)
