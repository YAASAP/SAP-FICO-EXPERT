FS00Déclarer un compte de rapprochement

Un compte de rapprochement relie un sous-ledger (clients, fournisseurs, immobilisations) à la comptabilité générale. Il se déclare au niveau société, dans les données de contrôle du compte.

Où ça se passe

Transaction FS00, vue société, onglet Type/Contrôle (données du compte au niveau société, table SKB1)

Les étapes

  1. Ouvre FS00, saisis le compte et la société, puis passe en modification.
  2. Va dans l'onglet Type/Contrôle.
  3. Renseigne « Compte de rapprochement pour type de compte » : clients, fournisseurs ou immobilisations selon le sous-ledger concerné.
  4. Enregistre, puis renseigne ce compte dans la fiche client ou fournisseur concernée.

Le piège

Une fois ce paramétrage posé, le compte n'accepte plus de saisie directe : toute écriture passe par le sous-ledger. Choisis le bon type dès la création, car le corriger sur un compte déjà utilisé est délicat.

Pour vérifier

Tente une écriture directe sur ce compte avec FB50 : SAP doit la refuser, puis passe la même écriture via une facture client ou fournisseur.
